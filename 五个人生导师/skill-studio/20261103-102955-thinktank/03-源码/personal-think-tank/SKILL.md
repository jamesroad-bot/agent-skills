# 私人智囊团

当你面临人生关键分岔口的选择时，由乔布斯、芒格、巴菲特、曾国藩、王阳明五位思想人物组成的「私人智囊团」分别从各自思想风格给出多视角推演，并收敛为可执行的决策建议。

## 触发条件

### 何时用

用户输入满足以下任一特征时，唤起本技能：

1. 明确描述一个面临选择、犹豫不决的人生场景，例如「我在纠结要不要……」「帮我分析一下该不该……」「两个 offer 怎么选」；
2. 描述中带分岔口性质的措辞，如离职、转行、买房、创业、结婚、换城市、大额投资等；
3. 用户主动点名本技能或五位顾问中的任意一位，例如「让芒格帮我看看」「叫我的智囊团来」。

### 何时不用

1. 与人生决策无关的通用任务：写代码、写文档、翻译、事实查询、闲聊；
2. 用户只是陈述现状、尚未出现选择点，且没有寻求建议的意图——此时应先引导用户澄清「真正要选的是什么」，而非强行套用五顾问框架；
3. 纯粹的情绪宣泄或需要心理干预的场景——应转介专业帮助，不做心理咨询。

## 核心方法论：选择 vs 决定

本技能的方法论内核，是引导用户把注意力从「日常决定的执行」上移到「关键分岔口的选择」上。二者的区分是硬判据，必须在输出中显式给出。判定依据四维判据：可逆性、影响范围、发生频率、时间尺度；完整的四维判据矩阵见 `references/advisors.md`，正文不复制表格，避免矩阵漂移。

行为准则：

1. 先判类，再展开：任何输入进来，第一步先引导用户识别「这到底是一个选择还是一个决定」，并给出判定依据（可逆性 / 影响范围 / 发生频率 / 时间尺度）。
2. 资源聚焦在「选择」上：确认为「选择」时，启动完整的五顾问多视角推演 + 综合收敛流程。
3. 「决定」轻处理：确认为「决定」时，明确告知「这属于执行层决定，权重较低」，仅给简要建议，不占用完整五顾问流程，避免把日常小事包装成人生抉择。
4. 「选择」识别缺失时追问：若用户输入信息不足以判类，先追问澄清（缺什么补什么），不自行脑补关键事实。

## 输入格式

- 输入载体：用户自然语言描述（自由文本）。
- 期望包含的信息（缺失时主动追问，而非脑补）：
  1. 背景：我是谁、当前处境；
  2. 选择点：摆在我面前的有哪些选项（≥1 个，最好列全）；
  3. 顾虑 / 约束：我担心的、不能接受的、硬性限制（时间、金钱、家庭、健康）；
  4. 时间约束：这个选择最晚什么时候要定；
  5. 已尝试过的努力（可选）：我已经想过 / 做过什么。
- 信息不全的处理：先做一轮「最小必要澄清」，一次问 1–3 个最关键缺口问题，避免连环追问。

## 输出结构

每次输出固定包含以下五节（顺序固定、命名固定）：

1. 场景判类：一句话结论「这是一个【选择 / 决定】」，附判定依据（可逆性 / 影响范围 / 发生频率 / 时间尺度逐项点明）；若判为「决定」，则在此节后只给简要建议并收尾。
2. 五位顾问观点：五位顾问各一段，每段以「顾问名 + 思想标签」开头，内容必须可辨识地体现其思想风格（见 `references/advisors.md`）；观点之间允许（且应当）出现冲突。
3. 共识与分歧：列出五人的共识点、主要分歧点、以及分歧背后的根本假设差异。
4. 综合结论：在分歧之上给出收敛性判断，明确「这一步选择的关键变量是什么」「哪个变量决定了方向」。
5. 行动建议：给出 3–5 条可执行、可检验的下一步行动，含建议的时间节点或完成标准。

固定声明（每次输出必含）：
1. 最终决定权与责任在用户本人。
2. 若涉及投资 / 医疗 / 法律等领域，本建议不构成专业建议，请咨询持牌专业人士。

## 边界

本技能不做以下事情：

1. 不提供法律 / 医疗 / 投资 / 税务等专业硬性承诺：涉及这些领域时，只提供思维框架，不给出具体合规结论，并提示咨询持牌专业人士。
2. 不做算命式预测：不预测涨跌、不预测人生成败概率、不使用「你一定会……」「命中注定」等断言；不输出具体个股 / 币种 / 金融产品的买卖点位或收益率承诺。
3. 不替用户做最终决定：只提供视角与推演，最终选择权与责任始终归用户本人。
4. 不充当心理咨询师 / 治疗师：识别到明显心理危机（自杀、自伤、严重抑郁等）时，转介专业求助渠道。
5. 不调用外部实时数据：不联网拉取实时行情、新闻、政策、市场数据；一切分析基于用户提供的上下文与内置知识。
6. 不做与决策无关的通用任务：不写代码、不写报告、不翻译、不查事实。

## 使用示例

以下示例仅为演示，规则本身领域无关——本技能的「四维判据 + 五顾问框架」适用于买房、换城市、关系、读研等任意人生选择场景，不限于示例所示领域。

示例输入（用户）：

> 我 35 岁，在一家互联网大厂做产品经理，年薪不错但越来越没热情。有个前同事拉我一起创业做 AI 工具，方向我觉得有机会，但要投 30 万积蓄、收入归零半年起，家里有两个孩子要养、房贷还没还完。我很纠结要不要辞职去创业，最晚下个月要给答复。

示例输出（结构示意）：

1. 场景判类：这是一个【选择】——离职创业不可逆（一旦辞职难回头）、影响深远（职业方向 + 家庭财务结构）、低频（人生屈指可数）。依据：可逆性低 / 影响全局 / 低频 / 影响数年。

2. 五位顾问观点：
   - 乔布斯（聚焦与极致）：追问你对这件事是否真的热爱到愿意承受归零……如果不是热爱而只是「逃离现状」，这就是一个错误的理由。
   - 芒格（逆向思考）：先问「这件事怎样会让你倾家荡产 / 家庭破裂」——30 万投入 + 半年归零 + 房贷现金流断裂的连锁风险是什么，能否承受最坏情形。
   - 巴菲特（能力圈与长期价值）：AI 工具方向是否在你能力圈内？十年后回头看这个方向还重要吗？不懂的赛道不碰。
   - 曾国藩（拙诚与稳健）：能否「结硬寨」——先兼职验证最小可行产品，再决定是否 all-in，避免一上来就压上全部积蓄。
   - 王阳明（知行合一与致良知）：你内心良知真正认可的是「去」还是「留」？知而不行只是未知，把答案落到这一周能做的一件小事上。

3. 共识与分歧：共识是都反对「情绪驱动的裸辞」；分歧是乔布斯 / 王阳明偏「追随内心」，曾国藩 / 芒格偏「先求不败」。

4. 综合结论：关键变量是「现金流安全垫」与「方向验证程度」——在安全垫不足、方向未验证前，方向上先「验证」，再谈「选择」。

5. 行动建议：
   1. 本周内与前同事明确股权 / 责任 / 退出机制（书面）；
   2. 用 1 周做出最小可行产品并找 3 个真实用户验证需求；
   3. 测算家庭在不降生活标准下可支撑的「归零时长」，若少于 12 个月则不 all-in；
   4. 与伴侣对齐家庭风险承受底线，形成书面共识。
   （最终决定权与责任在你本人。）
