# 内置知识：五位顾问与选择/决定判据

## 一、选择 vs 决定 四维判据矩阵

| 判断维度 | 选择（Choice） | 决定（Decision） |
|------|------|------|
| 可逆性 | 不可逆，或逆转成本极高 | 可逆，或低成本即可修正 |
| 影响范围 | 深远、全局、结构性 | 局部、短期、执行性 |
| 发生频率 | 低频（人生屈指可数） | 高频（日常反复发生） |
| 时间尺度 | 影响数年乃至数十年 | 影响数天至数周 |
| 典型示例 | 换行业、是否创业、是否成家、换城市、大额资产配置方向 | 今天先做哪件事、开哪场会、回复哪封邮件 |

## 二、五位顾问思想风格卡片

| 顾问 | 思想标签 | 核心视角（供 LLM 生成观点时对齐） |
|------|------|------|
| 乔布斯 | 聚焦与极致（focus & simplicity，stay hungry, stay foolish） | 追问「这件事是不是你真正热爱的」「如果只剩三个选项你会砍掉哪个」；强调把资源集中到极少数真正重要的东西上，敢于舍弃。 |
| 芒格 | 多元思维模型与逆向思考（invert, always invert） | 先问「怎样会失败 / 怎样会把事情搞砸」，再倒推规避；用多学科视角交叉检验，警惕单一框架与认知偏误。 |
| 巴菲特 | 能力圈与长期价值（circle of competence，long-term compounding） | 追问「这是否在你的能力圈内」「十年后回头看这还重要吗」；强调长期复利、拒绝不懂的诱惑、留有安全边际。 |
| 曾国藩 | 自我修炼与稳健（拙诚、日课、稳扎稳打） | 强调「结硬寨、打呆仗」，不取巧、不冒进；用日课与自我约束对抗浮躁，先求不败再求胜。 |
| 王阳明 | 知行合一与致良知（knowing-doing unity，conscience） | 追问「你内心良知真正认可的方向是什么」；强调知而不行只是未知，把判断落到行动上，以内心是非为准绳。 |

## 三、顾问观点生成约束

- 每位顾问一段，以「顾问名 + 思想标签」开头，例如「乔布斯（聚焦与极致）」，观点必须可辨识地体现其思想风格（QA 对照上表卡片核验）。
- 观点之间允许且应当出现冲突：不同顾问基于不同思想立场，对同一场景给出不同甚至相反的建议是正常的，不要强行调和。
- 卡片描述的是「通用思想风格」，不限定于某个具体领域（防窄化）：生成观点时把该思想风格应用到用户当前场景，而非套用某个示例的结论。
