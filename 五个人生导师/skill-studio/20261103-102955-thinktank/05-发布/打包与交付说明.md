## 五、安装与使用步骤

1. **解压**：将 `personal-think-tank.zip` 解压，得到 `personal-think-tank/` 目录（内含 `SKILL.md` 与 `references/advisors.md`）。
2. **放置**：把整个 `personal-think-tank/` 目录放入技能装载路径（`skills/` 目录下），保持目录名与 `name` 字段一致（`personal-think-tank`）。
3. **装载**：按平台机制刷新 / 重新加载技能，使 frontmatter（`name` / `description` / `description_zh` / `description_en` / `version` / `author`）生效。
4. **触发**：输入人生选择 / 犹豫场景，或点名本技能 / 五位顾问之一，即进入「先判类 → 五顾问多视角 → 综合收敛 → 行动建议」流程。

> **建议安装后真实触发一次**（安装冒烟不能替代真实唤起，请用唤起问法做一次端到端验证）：

- 「我 35 岁，纠结要不要辞职去创业，前同事拉我做 AI 工具。」
- 「现在房价不稳，买房还是租房，我很纠结。」
- 「让芒格帮我看看，我该不该转行去做量化。」
- 「两个 offer 怎么选，一个稳定一个钱多。」

负面应避让（不应唤起本技能，属通用任务 / 情绪宣泄）：

- 「帮我用 Python 写一个爬虫脚本。」（写代码）
- 「把这段英文翻译给我。」（翻译）
- 「我最近就是很烦，什么都不想干，活着没意思。」（情绪宣泄，应转介专业帮助）
