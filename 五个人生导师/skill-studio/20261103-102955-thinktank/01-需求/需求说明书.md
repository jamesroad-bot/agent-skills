> 版本：v1.0（Phase 1 构思产物）
> 作者：许思清（技能产品经理 / skill-ideator）

---

## 一、技能名称与一句话定位

- **技能文件名（name，即目录名）**：`personal-think-tank`
- **一句话定位**：当用户面临人生关键分岔口的选择时，由乔布斯、芒格、巴菲特、曾国藩、王阳明五位思想人物组成的「私人智囊团」分别从各自思想风格给出视角，综合成可执行的决策建议。

> 命名依据：workbuddy 平台命名规则 `^[a-z0-9][a-z0-9-]*[a-z0-9]$`（全小写、禁下划线、禁连续/首尾连字符、长度 2–64）。`personal-think-tank` 合规且语义贴切（personal=个人决策场景，think-tank=智囊团）。

---

## 二、目标用户

- **谁在用**：面临人生关键决策、希望获得多视角参考的普通成年人——不要求投资 / 法律 / 心理专业背景。
- **典型画像**：
  - 职业：纠结是否跳槽、转行、离职创业、接受外派；
  - 投资：纠结买房 vs 租房、大额资金如何配置、是否加杠杆；
  - 人际：纠结是否结束一段关系、是否坦白、如何处理家庭重大分歧；
  - 成长：纠结是否读研、是否投入多年学一门技能、是否改变生活城市。
- **使用场景特征**：用户往往已思考多时、信息不全、情绪与理性混杂、缺少「另一双眼睛」，希望在动手决定前做一次结构化、多视角的推演。

## 四、触发场景

### 4.1 何时触发（应当唤起）

用户输入满足以下任一特征时，唤起本技能：

1. 明确描述一个**面临选择 / 犹豫不决**的人生场景，例如「我在纠结要不要……」「帮我分析一下该不该……」「两个 offer 怎么选」；
2. 描述中带**分岔口性质**的措辞（离职、转行、买房、创业、结婚、换城市、大额投资等）；
3. 用户主动点名本技能或五位顾问中的任意一位（如「让芒格帮我看看」「叫我的智囊团来」）。

### 4.2 何时不该触发（不应唤起）

1. 与人生决策无关的通用任务：写代码、写文档、翻译、事实查询、闲聊；
2. 用户只是陈述现状、**尚未出现选择点**，且没有寻求建议的意图（此时应引导用户先澄清「真正要选的是什么」，而非强行套用五顾问框架）；
3. 纯粹的情绪宣泄或需要心理干预的场景（应转介专业帮助，不做心理咨询）。

## 五、核心方法论：「选择大于决定」的精确区分

本技能的方法论内核，是引导用户把注意力从「日常决定的执行」上移到「关键分岔口的选择」上。二者的区分是**硬判据**，必须在输出中显式给出：

| 判断维度 | 选择（Choice） | 决定（Decision） |
|------|------|------|
| 可逆性 | 不可逆，或逆转成本极高 | 可逆，或低成本即可修正 |
| 影响范围 | 深远、全局、结构性 | 局部、短期、执行性 |
| 发生频率 | 低频（人生屈指可数） | 高频（日常反复发生） |
| 时间尺度 | 影响数年乃至数十年 | 影响数天至数周 |
| 可修正性 | 难以修正、路径依赖强 | 易于修正、试错成本低 |
| 典型示例 | 换行业、是否创业、是否成家、换城市、大额资产配置方向 | 今天先做哪件事、开哪场会、回复哪封邮件 |

**技能的行为准则**：

1. **先判类，再展开**：任何输入进来，第一步是引导用户识别「这到底是一个选择还是一个决定」，并给出判定依据（可逆性 / 影响范围 / 频率 / 时间尺度）。
2. **资源聚焦在「选择」上**：确认为「选择」时，启动完整的五顾问多视角推演 + 综合收敛流程。
3. **「决定」轻处理**：确认为「决定」时，明确告知「这属于执行层决定，权重较低」，仅给简要建议，不占用完整五顾问流程，避免把日常小事包装成人生抉择。
4. **「选择」识别缺失时追问**：若用户输入信息不足以判类，先追问澄清（缺什么补什么），不自行脑补关键事实。

## 六、核心能力

1. **选择 / 决定判类**：依据可逆性、影响范围、频率、时间尺度四维判据，判定当前问题属于「选择」还是「决定」，并给出依据。
2. **五位顾问多视角分析**：按各自思想风格，输出五位顾问对同一场景的差异化视角（详见第七节数据来源中的思想风格卡片）。
3. **综合收敛**：识别五位顾问观点的共识点、分歧点与互补点，收敛成一份「综合结论」。
4. **可执行行动建议**：输出有步骤、有（可选的）时间节点、可立即落地的下一步行动清单。
5. **边界守护**：在涉及投资 / 医疗 / 法律等专业领域时，自动附加「不构成专业建议」的边界声明，拒绝算命式预测与具体标的买卖指令。

---

## 七、输入格式

- **输入载体**：用户自然语言描述（自由文本）。
- **期望包含的信息**（缺失时技能应主动追问，而非脑补）：
  1. **背景**：我是谁、当前处境；
  2. **选择点**：摆在我面前的有哪些选项（≥1 个，最好列全）；
  3. **顾虑 / 约束**：我担心的、不能接受的、硬性限制（时间、金钱、家庭、健康）；
  4. **时间约束**：这个选择最晚什么时候要定；
  5. **已尝试过的努力**（可选）：我已经想过 / 做过什么。
- **信息不全的处理**：技能先做一轮「最小必要澄清」，一次问 1–3 个最关键缺口问题，避免连环追问。

---

## 八、输出结构

每次输出固定包含以下五节（顺序固定、命名固定）：

1. **场景判类**：一句话结论「这是一个【选择 / 决定】」，附判定依据（可逆性 / 影响范围 / 频率 / 时间尺度逐项点明）；若判为「决定」，则在此节后只给简要建议并收尾。
2. **五位顾问观点**：五位顾问各一段，每段以「顾问名 + 思想标签」开头，内容必须可辨识地体现其思想风格（见第十一节思想风格卡片）。观点之间允许（且应当）出现冲突。
3. **共识与分歧**：列出五人的共识点、主要分歧点、以及分歧背后的根本假设差异。
4. **综合结论**：在分歧之上给出收敛性判断，明确「这一步选择的关键变量是什么」「哪个变量决定了方向」。
5. **行动建议**：给出 3–5 条可执行、可检验的下一步行动，含建议的时间节点或完成标准；并明确「最终决定权与责任在用户本人」。

## 九、边界（明确不做什么）

1. **不提供法律 / 医疗 / 投资 / 税务等专业硬性承诺**：涉及这些领域时，只提供思维框架，不给出具体合规结论，并提示咨询持牌专业人士。
2. **不做算命式预测**：不预测涨跌、不预测人生成败概率、不使用「你一定会……」「命中注定」等断言；不输出具体个股 / 币种 / 金融产品的买卖点位或收益率承诺。
3. **不替用户做最终决定**：只提供视角与推演，最终选择权与责任始终归用户本人。
4. **不充当心理咨询师 / 治疗师**：识别到明显心理危机（自杀、自伤、严重抑郁等）时，转介专业求助渠道。
5. **不调用外部实时数据**：不联网拉取实时行情、新闻、政策、市场数据；一切分析基于用户提供的上下文与内置知识。
6. **不做与决策无关的通用任务**：不写代码、不写报告、不翻译、不查事实。

## 十一、分工与数据来源（禁止假设数据存在）

### 11.1 数据来源（本技能的核心约束）

本技能的「五位顾问思想风格」与「选择 vs 决定判据」**不是运行时从外部获取的数据，而是随技能分发的内置静态知识**。具体方案：

- 将五位顾问的思想风格卡片、以及「选择 / 决定」四维判据矩阵，作为**内置知识静态写入技能文件**（建议 `references/advisors.md`），随技能打包分发。
- **不依赖任何外部 API、实时行情、新闻、用户数据库**；skill 在任何离线环境下均可完整运行。
- 技能运行时仅消费两类输入：① 用户本次提供的场景上下文；② 内置静态知识。除此之外不假设任何数据可用。

### 11.2 内置知识：五位顾问思想风格卡片（建议写入 references/advisors.md）

| 顾问 | 思想标签 | 核心视角（供 LLM 生成观点时对齐） |
|------|------|------|
| 乔布斯 | 聚焦与极致（focus & simplicity，stay hungry, stay foolish） | 追问「这件事是不是你真正热爱的」「如果只剩三个选项你会砍掉哪个」；强调把资源集中到极少数真正重要的东西上，敢于舍弃。 |
| 芒格 | 多元思维模型与逆向思考（invert, always invert） | 先问「怎样会失败 / 怎样会把事情搞砸」，再倒推规避；用多学科视角交叉检验，警惕单一框架与认知偏误。 |
| 巴菲特 | 能力圈与长期价值（circle of competence，long-term compounding） | 追问「这是否在你的能力圈内」「十年后回头看这还重要吗」；强调长期复利、拒绝不懂的诱惑、留有安全边际。 |
| 曾国藩 | 自我修炼与稳健（拙诚、日课、稳扎稳打） | 强调「结硬寨、打呆仗」，不取巧、不冒进；用日课与自我约束对抗浮躁，先求不败再求胜。 |
| 王阳明 | 知行合一与致良知（knowing-doing unity，conscience） | 追问「你内心良知真正认可的方向是什么」；强调知而不行只是未知，把判断落到行动上，以内心是非为准绳。 |

### 11.3 LLM / 脚本分工

| 环节 | 责任方 | 说明 |
|------|------|------|
| 触发判断（是否唤起本技能） | LLM（意图理解） | 依据第四节触发条件判断 |
| 选择 / 决定判类 | LLM（分类 + 推理） | 依据第五节四维判据矩阵（内置知识） |
| 澄清追问 | LLM（对话生成） | 信息不全时生成针对性追问 |
| 五位顾问观点生成 | LLM（生成） | 对齐 11.2 思想风格卡片，产出差异化观点 |
| 共识 / 分歧收敛 | LLM（综合生成） | 识别共识点与分歧点 |
| 综合结论与行动建议 | LLM（生成） | 产出可执行建议 |
| 输出结构模板 / 固定节名 / 免责声明 | **静态资源（内置）** | 由 SKILL.md 正文的「输出规范」与固定文案提供，保证结构稳定、边界声明不丢失 |
| 确定性代码脚本 | **无（本技能为纯 LLM 驱动 + 内置静态知识）** | 无需脚本做校验 / 转换 / 聚合；如后续需对输出做结构自检，可加最小脚本，但 v1.0 不做 |

> 结论：本技能是「纯 LLM 驱动 + 内置静态知识」型技能，v1.0 不引入脚本，不引入外部数据依赖。这同时降低了断链 / 敏感信息 / 硬编码 / 运行时兼容性风险。

## 十二、使用示例

### 示例输入（用户）

> 我 35 岁，在一家互联网大厂做产品经理，年薪不错但越来越没热情。有个前同事拉我一起创业做 AI 工具，方向我觉得有机会，但要投 30 万积蓄、收入归零半年起，家里有两个孩子要养、房贷还没还完。我很纠结要不要辞职去创业，最晚下个月要给答复。

### 示例输出（结构示意，非全文）

**1. 场景判类**
这是一个【选择】——离职创业不可逆（一旦辞职难回头）、影响深远（职业方向 + 家庭财务结构）、低频（人生屈指可数）。依据：可逆性低 / 影响全局 / 低频 / 影响数年。

**2. 五位顾问观点**
- 乔布斯（聚焦与极致）：追问你对这件事是否真的热爱到愿意承受归零……如果不是热爱而只是「逃离现状」，这就是一个错误的理由。
- 芒格（逆向思考）：先问「这件事怎样会让你倾家荡产 / 家庭破裂」——30 万投入 + 半年归零 + 房贷现金流断裂的连锁风险是什么，能否承受最坏情形。
- 巴菲特（能力圈与长期价值）：AI 工具方向是否在你能力圈内？十年后回头看这个方向还重要吗？不懂的赛道不碰。
- 曾国藩（拙诚与稳健）：能否「结硬寨」——先兼职验证最小可行产品，再决定是否 all-in，避免一上来就压上全部积蓄。
- 王阳明（知行合一与致良知）：你内心良知真正认可的是「去」还是「留」？知而不行只是未知，把答案落到这一周能做的一件小事上。

**3. 共识与分歧**
共识：都反对「情绪驱动的裸辞」；分歧：乔布斯 / 王阳明偏「追随内心」，曾国藩 / 芒格偏「先求不败」。

**4. 综合结论**
关键变量是「现金流安全垫」与「方向验证程度」——在安全垫不足、方向未验证前，方向上先「验证」，再谈「选择」。

**5. 行动建议**
1. 本周内与前同事明确股权 / 责任 / 退出机制（书面）；
2. 用 1 周做出最小可行产品并找 3 个真实用户验证需求；
3. 测算家庭在不降生活标准下可支撑的「归零时长」，若 < 12 个月则不 all-in；
4. 与伴侣对齐家庭风险承受底线，形成书面共识。
（最终决定权与责任在你本人。）
