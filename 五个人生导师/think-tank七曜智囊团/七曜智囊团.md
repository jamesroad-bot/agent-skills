### 新增 `server.js`（148 行，零依赖，只用 Node 内置模块）

```
浏览器  →  http://127.0.0.1:8788/            同源页面
        →  http://127.0.0.1:8788/__ollama/*  同源转发
        →  Node 服务端  →  http://127.0.0.1:11434/api/*   无 CORS 概念
```

它负责托管 `index.html`、把 `/__ollama/*` 原样转发给 Ollama、统一回 `Access-Control-Allow-Origin: *`、把上游失败转成 502 并附上清晰提示，并把 `requestTimeout` 置 0 以适配 7B 冷加载。端口、监听地址、Ollama 地址都可用环境变量覆盖。

### `index.html` 的配套改动（1303 行 / 90,034 字节）

- **自动探测**：页面加载时依次尝试「同源 `/__ollama`」和「`127.0.0.1:8788/__ollama`」，各 1.5 秒超时；命中就切换到转发路径，全部失败则静默回退直连，不影响内置推演。
- **来源徽标**显示为「本地模型 qwen2.5:7b（单次成篇） · 免跨域转发」，一眼能看出走的是哪条路。
- **手动优先**：一旦你改了地址输入框，就清掉代理标记、改为直连，避免两者状态混淆。
- **错误提示更准确**：转发返回 502 时，直接显示「本地服务无法连上 Ollama：…」，不再叠加“检查地址”这类猜测。
