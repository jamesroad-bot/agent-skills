# 核心提问策略（五类）

本文件定义五类提问的用途、中文句式、编排逻辑与硬约束。所有句式为**默认中文文案**；当 `language` 为 `en` 或 `auto` 时按参数契约切换语言，但中立、不评判、不泄露结论的要求在任何语言下不变。

## 通用生成规则（每一问都适用）

- **一次一问**：一轮只输出一个主问题，不把多个问题并置成连珠炮。
- **锚定上一轮**：问题必须显式承接用户最近一次回答中的某个具体点（用词、假设、缺口、矛盾）。
- **开放式优先**：以"是什么 / 为什么 / 如何 / 凭什么 / 如果……会怎样"为主；需收敛时用中性措辞，不用"是不是其实……"这类诱导句式。
- **零评判**：不复述性地说"很好/不对/显然"，不暗示对错。
- **不泄露预设结论**：不得把助手认为的"正确答案"编码进问题方向。

## 策略 1：澄清概念（clarify_concepts）

- 用途：确认用户在说什么、关键术语何指、真实关切在哪。
- 适用时机：开局，或当回答含糊、术语含混时优先使用。
- 中文句式：
  - 你说的"<用户用词>"，在你这里具体指什么？
  - 如果要把这个问题讲给一个完全不了解的人，你会怎么定义它？
  - 这里你最想弄清楚的是哪一点？
  - 你能举一个具体的例子来说明你指的这种情况吗？

## 策略 2：检验证据（examine_evidence）

- 用途：追问依据、来源、可证伪性与推理链。
- 适用时机：用户抛出判断/断言/结论性表述之后。
- 中文句式：
  - 让你这样判断的依据主要有哪些？
  - 这些依据里，你觉得最可靠的是哪一条？为什么？
  - 有没有什么情况一旦出现，你会改变现在的看法？
  - 从你掌握的信息到你得出的结论，中间还缺哪一步？

## 策略 3：挑战假设（challenge_assumptions）

- 用途：把未言明的前提摆到台面上，检验其成立条件。
- 适用时机：回答里反复出现某个隐含前提，或推理"想当然"时。
- 中文句式：
  - 这个想法成立，需要哪些你认为不用证明的前提？
  - 如果我们把"<隐含假设>"这条假设拿掉，结论会怎样？
  - 你凭什么认为这件事一直是这样的？有没有例外？
  - 换一个时间或场景，这个前提还成立吗？

## 策略 4：探索替代视角（explore_alternatives）

- 用途：引入反例、他人立场、换位与反面可能，扩大解空间。
- 适用时机：用户视角单一、或已出现停滞/重复时。
- 中文句式：
  - 一个和你立场完全不同的人，会怎么看你刚才说的？
  - 还有没有别种解释，也能说得通？
  - 如果你必须为相反的观点辩护，你会讲什么理由？
  - 有没有一个反例，能同时说明问题不止一种看法？

## 策略 5：引导反思（guide_reflection）

- 用途：回看整段推理，指出盲点，让用户自评结论的稳健性。
- 适用时机：接近收尾、或已澄清+证据+假设都过了一遍时。
- 中文句式：
  - 绕了这一圈，你对最初那个问题的看法有什么变化吗？
  - 现在回看，你觉得哪里还最不确定？
  - 如果要用一句话总结你自己想清楚的部分，你会怎么说？
  - 接下来你打算怎么验证你现在的想法？

## 编排逻辑（默认）

1. 默认推进顺序：澄清概念 → 检验证据 → 挑战假设 → 探索替代视角 → 引导反思。
2. **动态跳过**：某策略已充分覆盖且无明显缺口时，可跳过，不必机械遍历。
3. **回环**：新信息出现可回到"澄清/检验"再补一轮，但同一条线索连续追问 ≤ 2 轮。
4. **覆盖度驱动**：优先推进 `covered_strategies` 之外、且能利用 `open_threads` 的策略。
5. **轮次感知**：剩余轮次不足时，收敛到 2–3 个最有价值的问题，并在触及上限前预留 1 轮做反思。

## 中立与不泄露红线（示例对照）

| 不合格（泄露/评判/诱导） | 合格（中立开放） |
|--------------------------|------------------|
| "你不觉得这个方案明显有问题吗？" | "你觉得这个方案里，哪些地方可能带来风险？" |
| "正确答案难道不是 A 吗？" | "在你看来 A 和 B 各自的依据是什么？" |
| "这个回答太浅了，再想想。" | "关于这一点，还能再多说一些具体情形吗？" |
| "所以我前面说的对吧？" | "结合你说的，你自己更倾向于哪种理解？" |
