# 示例输入 / 输出与完整样张

默认交互文案为中文。以下示例展示：启动包写法、单轮"问题+中立复述"输出格式、两段多轮追问、以及到点输出的结构化反思总结。

## 一、启动包（示例输入）

示例 A（只给主题，其余用默认）：
```
topic: 我在纠结要不要辞职去读研
```

示例 B（含可配置参数）：
```
topic: 我们这款新功能该不该现在上线
goal: 分清"想上线"背后的事实依据与情绪假设
audience_level: advanced
max_rounds: 5
end_condition: goal_met_or_rounds_exhausted
tone: neutral
language: zh
```

## 二、单轮输出格式（示例输出）

对每一轮，输出 = 一句中立复述（反映用户原话）+ 恰好一个问题。

```
你提到"担心现在上线数据不好看"。
那么，支撑"现在必须上线"这个判断的依据主要有哪些？
```

> 注：复述只转述用户自己说过的内容，不含评价，也不暗示答案。

## 三、完整样张 1（辞职读研，默认 6 轮，示例 A）

- 助手（澄清概念，R1）：先对齐一下——你说的"读研"，对你来说最主要意味着什么，是换个方向、暂缓就业，还是别的？
- 用户：更像是想换个方向，现在的工作感觉没成长。
- 助手（检验证据，R2）：你说"现在的工作没成长"。让你得出这个判断的具体证据有哪些？
- 用户：一年了没接手过新项目，领导也不太安排事给我。
- 助手（挑战假设，R3）：这里似乎有一个前提——"能成长=被安排新项目"。你凭什么认为成长只能来自这一条？还有别的可能吗？
- 用户：嗯……也许也能靠自己找活，但环境确实没什么空间。
- 助手（探索替代视角，R4）：如果一个和你立场不同的人来看你的处境，他可能会说"先内部争取，别急着用学历解决"。你觉得他会基于什么理由这样讲？
- 用户：他可能觉得读研成本高、也不保证回来就有成长。
- 助手（引导反思，R5）：绕到现在，你对最初"要不要辞职读研"的看法，和你一开始比有什么变化？
- 用户：我意识到我其实是在用读研来回避"当前没主动争取"这件事。
- 助手（引导反思，R6）：那用一句话总结你自己想清楚的部分，你会怎么说？
- 用户：我先该确认的是能否在当前环境主动争取成长，而不是默认读研是唯一出路。
- 助手：触及轮次上限（6 轮），输出反思总结 ↓

```
【引导式追问总结 · 主题：要不要辞职去读研】
- 核心议题：在当前工作"没成长"的感受下，是否用辞职读研作为出路。
- 已澄清的关键点：不满主要来自"一年没接新项目、被安排少"；成长被等同于"被安排新项目"。
- 浮现出的假设：假设成长只能来自外部安排；假设读研能带来方向与成长。
- 考虑过的替代视角：先内部主动争取；读研成本高且不保证回报。
- 尚未解决的问题：当前环境是否真无争取空间；若争取无果，读研是否为优选。
- 你自己的结论 / 下一步：先确认能否在当前环境主动争取成长，而非默认读研是唯一出路。
```

## 四、完整样张 2（功能是否现在上线，advanced，示例 B）

- 助手（澄清概念，R1）：先界定一下——"现在上线"对你而言最核心要达成的是什么（抢时间窗、验证需求，还是别的）？
- 用户：主要是验证需求，怕做出来没人用。
- 助手（检验证据，R2）：那"怕做出来没人用"这个担心，有没有已经收集到的信号支撑？还是更多是推测？
- 用户：有一些用户访谈，但样本不大，也就 5 个人。
- 助手（挑战假设，R3）：这里隐含一个假设——"上线就能验证需求"。除了上线，还有没有更低成本的方式能先验证？
- 用户：可以做个落地页测点击，但我们觉得开发已经差不多了。
- 助手（探索替代视角，R4）：如果站在反对"现在上"的人角度看，"开发已经差不多了"会不会恰恰是一个需要警惕的理由？为什么？
- 用户：可能……因为它让我把"沉没成本"当成了"该上"的依据。

- 判定：`goal`（分清事实依据与情绪假设）已达成，提前收尾（未用满 5 轮），输出反思总结 ↓

```
【引导式追问总结 · 主题：新功能是否现在上线】
- 核心议题：是否以"现在上线"来验证需求。
- 已澄清的关键点：上线动机=验证需求；证据=5 人访谈（样本小）。
- 浮现出的假设：假设"上线=最佳验证方式"；把"开发已完成"当作应当上线的理由（沉没成本）。
- 考虑过的替代视角：用落地页等低成本方式先验证。
- 尚未解决的问题：小样本访谈是否足以支撑上线决策。
- 你自己的结论 / 下一步：先区分"想验证需求"的事实依据与"已投入所以该上"的情绪假设。
```

## 五、边界处理示例（拒答 → 降级）

- 用户：不知道，你直接说怎么办吧。
- 助手：可以，我先给你一句方向（简要）。如果你愿意，我们再回到用问题帮你把这点想透——你想我继续问，还是就到这里？
