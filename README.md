# Agent Skills 合集：私人智囊团 · 苏格拉底提问法

个人 Agent Skills 项目与原型实验的归档仓库，围绕两组主题：

- **多视角决策** —— 用多位思想者的立场，帮人想清楚人生关键分岔口的「选择」。
- **引导式追问** —— 不直接给答案，用一轮一问把人问到自己想清楚。

> 这里收录的是设计稿、提示词草案、Skill 源码、打包产物，以及本地可运行的单文件网页原型；**不是上架发布包**，也不保证可直接安装到所有 Agent。仓库共 65 个原始文件，本 README 是后来补的说明文档。

## 一、五个人生导师 · 私人智囊团

### 用途

核心方法论是 **「选择大于决定」**：先用「可逆性 / 影响范围 / 发生频率 / 时间尺度」四维判据，区分高权重的**关键选择**与低权重的**执行层决定**；只有判为「选择」才启动完整的多视角推演。

正式 Skill 版的输出固定五节：

1. 场景判类（附四维判据）
2. 五位顾问观点（乔布斯、芒格、巴菲特、曾国藩、王阳明，观点允许冲突）
3. 共识与分歧（含分歧背后的假设差异）
4. 综合结论（指出决定方向的关键变量）
5. 行动建议（3–5 条可执行、可检验的下一步）

早期设定稿里另有**三套备选阵容**（古今统一场 / 商业与进化论 / 文明与大历史）和**三种互动模式**（圆桌辩论、漏斗式三阶决策、首席顾问一对一）。

### 三条演进线

1. **提示词草案**（根目录几个 `.md`）：最初的思路、角色句式与需求澄清方式。
2. **正式 Skill**（`skill-studio/`）：按「需求 → 设计 → 源码 → QA → 发布 → 沉淀」完整流程产出的 `personal-think-tank`，可安装到支持 `SKILL.md` 的 Agent。
3. **七曜智囊团网页原型**（`think-tank七曜智囊团/`）：把方法论做成离线单页应用。阴／阳／金／木／水／火／土七位专家（熊彼特、塔勒布、芒格、达尔文、孙武、乔布斯、曾国藩），支持点将、三种输出模式、阴阳天平、议事录累积与 Markdown 导出；后续增加本地 Ollama 同源代理，可选接真实本地模型。

## 二、苏格拉底提问法 · socratic-questioning

### 用途

面向「别直接给答案，请追问我」的场景：围绕给定主题做**引导式追问**，每轮输出**恰好一个问题**，问题必须锚定用户上一轮回答里的具体内容，全程保持中立、不评判、**不泄露预设结论**；到达结束条件时输出结构化反思总结。

- 五类策略：澄清概念 / 检验证据 / 挑战假设 / 探索替代视角 / 引导反思。
- 可配置参数：`topic`（必填）、`goal`、`audience_level`、`max_rounds`（1–20，默认 6）、`end_condition`、`tone`、`language`（默认中文）。
- 反思总结字段：核心议题 / 已澄清的关键点 / 浮现出的假设 / 考虑过的替代视角 / 尚未解决的问题 / 用户自己的结论或下一步。
- 明确的复用边界：事实查询、翻译、算账、安全合规等场景直接回答，不套追问。

## 说明与边界

- **本仓库是公开归档**，含过程记录与参考资料（提示词推演、`.workbuddy/memory/` 工作记忆、`data/` 本地数据、第三方电子书），并非全部为可复用代码。
- 所有「顾问观点」是基于思想风格库的**模拟推演**，不是真人言论；涉及投资、法律、医疗、税务时只提供思维框架，**不构成专业建议**。
- 七曜智囊团网页默认使用内置思想风格库，观点不是真实大模型输出；接入 Ollama 后才会由本地模型生成。
- 目录 `2026-10-29-12-52-16本地Ollama服务做同源代理/` 是「知屿 · 个人信息管家」的源码，作为「Node 同源转发、绕开浏览器跨域」方案的代码参考保留，与两个 Skill 本身无依赖关系。
- `socratic-questioning.zip` 是早期精简版，内容与当前完整 Skill 目录不同，以 `.skill` 包和 `socratic-questioning/` 目录为准。
- 未声明开源许可证；其中电子书为第三方作品，仅作个人归档。
